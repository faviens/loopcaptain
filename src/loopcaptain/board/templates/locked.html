Open the board from its own address

This browser has not been let in by the board that runs now.

  1. Find the terminal where loopcaptain serve (or make serve) runs. Its first line is an address that ends in a long key.
  2. Open that address in this browser. It lets this browser in and leads on to the board. It works once.

Every start of the board makes a new key, so an address from an earlier start no longer works, and a page left open across a restart ends up here. If this browser was let in already and a link from another program brought you here, enter the board's address in the address bar yourself.
